# TracerArm
A 4-DOF robotic arm that will be able to write on a whiteboard! This is my 1st independent hardware project with HackClub!

I started the project with the goal of learning a new mechanism, learn how to code a robot, and using old servos my robotics team does not use. I took heavy inspiration from robotic arms that used 4-bar linkages like the one I built where the end effector always stays parallel to the ground. Overall, the design was a big learning experience for me.
